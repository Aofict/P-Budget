วิธี Build Patch Update — P-Budget Manager
=========================================

ทำที่เครื่องผู้พัฒนา ใน Terminal แบบ PowerShell ของโฟลเดอร์โปรเจกต์
ตัวอย่างนี้สร้างแพตช์รุ่น 1.0.5 รองรับฐานรุ่น 1.0.1 ขึ้นไป
เครื่องปลายทางไม่ต้องมี EXE รุ่นใหม่ล่วงหน้า เพราะ ZIP แพตช์มีชุดโปรแกรมใหม่อยู่แล้ว

1. เตรียมเครื่องมือ (ทำครั้งแรก)
--------------------------------
ถ้ามี .venv-build และ PyInstaller พร้อมแล้ว ข้ามขั้นตอนนี้ได้

& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" -m venv .venv-build
.\.venv-build\Scripts\python.exe -m pip install -r requirements.txt pyinstaller

หากไม่พบ Python ให้เปลี่ยนเส้นทางเป็น Python 3.13 ที่ติดตั้งในเครื่อง

2. แก้เลขเวอร์ชันให้ตรงกัน 2 ไฟล์
--------------------------------
ไฟล์ patch_updates.py:
APP_VERSION = '1.0.5'

ไฟล์ release.json:
{"application": "PBudgetManager", "version": "1.0.5"}

รุ่นใหม่ต้องสูงกว่ารุ่นเดิม การเปลี่ยนชื่อ ZIP อย่างเดียวไม่ได้เปลี่ยนเวอร์ชัน

3. สร้าง EXE จากโค้ดล่าสุด
-------------------------
คัดลอกคำสั่งด้านล่างไปรันใน Terminal ตามลำดับ
กำหนดตัวแปรครั้งเดียว และใช้ Terminal เดิมจนจบขั้นตอน 4
ตัวแปร buildStamp ทำให้แต่ละครั้งสร้างในโฟลเดอร์ใหม่

$patchVersion = '1.0.5'
$minimumVersion = '1.0.1'
$buildStamp = Get-Date -Format 'yyyyMMdd-HHmmss-fff'
$patchDist = "dist/Release-$patchVersion-$buildStamp"
$patchWork = "build/Release-$patchVersion-$buildStamp"
$patchBundle = "$patchDist/PBudgetManager"
$patchZip = "dist/PBudgetManager-Patch-$patchVersion.zip"

.\.venv-build\Scripts\python.exe -m PyInstaller --noconfirm --distpath $patchDist --workpath $patchWork PBudgetManager.spec
if ($LASTEXITCODE -ne 0) { throw 'EXE build failed' }

รอจนเห็น Build complete! และไม่มีข้อผิดพลาด ก่อนทำขั้นตอนถัดไป
EXE ใหม่อยู่ใน $patchBundle พร้อมไฟล์ประกอบทั้งชุด
ต้อง Build EXE ใหม่ทุกครั้งหลังแก้โค้ด เพื่อให้แพตช์รวมการแก้ไขล่าสุด

4. สร้างไฟล์แพตช์ ZIP
---------------------
.\.venv-build\Scripts\python.exe build_patch.py $patchBundle $patchZip --minimum $minimumVersion --notes 'ระบุรายละเอียดที่ปรับปรุงในรุ่นนี้'
if ($LASTEXITCODE -ne 0) { throw 'Patch build failed' }
Get-Item -LiteralPath $patchZip

ไฟล์ที่ส่งให้เครื่องอื่นคือ ZIP ในโฟลเดอร์ dist ตามชื่อที่แสดง
ตัวอย่าง: PBudgetManager-Patch-1.0.5.zip

--minimum คือเวอร์ชันต่ำสุดที่อนุญาตให้อัปเดต ต้องกำหนดตามรุ่นที่รองรับจริง
หากรองรับตั้งแต่ 1.0.0 ให้เปลี่ยน $minimumVersion เป็น '1.0.0'
--notes คือรายละเอียดที่ผู้ใช้เห็นก่อนติดตั้ง
เวอร์ชันแพตช์อ่านจาก release.json ภายในชุด EXE ที่เพิ่ง Build

build_patch.py สร้าง patch.json พร้อม SHA-256 และเว้นโฟลเดอร์ data ของผู้ใช้
แพตช์เป็นชุดโปรแกรมเต็ม ห้ามสร้าง ZIP ด้วยการบีบอัดโฟลเดอร์เองแทนคำสั่งนี้

5. ตรวจสอบก่อนแจกจ่าย
---------------------
ทดลองเปิด EXE ใหม่และติดตั้งแพตช์กับชุดโปรแกรมและฐานข้อมูลสำเนา
ตรวจรุ่นใหม่ เปิดข้อมูลเดิม และตรวจฟังก์ชันที่แก้ไข
เมื่อพร้อมแล้วจึงส่ง ZIP ให้ผู้ใช้เครื่องอื่น

6. วิธีติดตั้งบนเครื่องอื่น
---------------------------
1) บันทึกงานที่ค้างอยู่ในโปรแกรมเดิม
2) ไปที่ ตั้งค่า > อัปเดตโปรแกรม
3) เลือก ZIP แพตช์ ตรวจสอบรุ่นและรายละเอียด
4) กด สำรองข้อมูลและติดตั้งแพตช์ แล้วรอจนเสร็จ
5) ตรวจเลขรุ่นและข้อมูลเดิม
6) ใช้ EXE ในโฟลเดอร์ใหม่ที่ระบบแจ้ง และปรับทางลัดให้ชี้ไปที่ไฟล์นั้น

เครื่องปลายทางไม่ต้องติดตั้ง Python หรือ Build EXE เอง
เมนูติดตั้งแพตช์รองรับ EXE แบบโฟลเดอร์ที่ใช้ data/master.db ข้าง EXE
โหมด python server.py หรือกำหนดฐานข้อมูลผ่าน P_BUDGET_DB จะติดตั้งผ่านเมนูนี้ไม่ได้
หากโปรแกรมเดิมไม่มีเมนูอัปเดต ต้องแจกชุดโปรแกรมใหม่ทั้งโฟลเดอร์ พร้อมย้ายข้อมูลเดิมตามขั้นตอนติดตั้ง ห้ามส่งเฉพาะ .exe

7. รุ่นถัดไปทำอย่างไร
----------------------
เปลี่ยนเลขเวอร์ชันทั้งสองไฟล์ในขั้นตอน 2 และ $patchVersion ในขั้นตอน 3 ให้ตรงกัน
กำหนด $minimumVersion ตามรุ่นฐานที่รองรับ แล้วทำขั้นตอน 3–6 ใหม่
ตัวอย่าง: 1.0.5 -> 1.0.6

ปัญหาที่พบบ่อย
---------------
- No module named PyInstaller: ติดตั้งเครื่องมือตามขั้นตอน 1
- รุ่นใหม่ไม่สูงกว่ารุ่นเดิม: ตรวจเลขรุ่นทั้งสองไฟล์ แล้ว Build EXE ใหม่
- ไม่พบ $patchBundle: รันขั้นตอน 3 ใหม่ใน Terminal เดียวกับขั้นตอน 4
- ZIP เดิมถูกแทนที่เมื่อสร้างแพตช์เวอร์ชันเดิมซ้ำ โดยเขียนไฟล์ใหม่ให้เสร็จก่อนสลับแทน
- ไฟล์ไม่ครบ: ใช้โฟลเดอร์ PBudgetManager ที่ PyInstaller สร้างทั้งชุด
- อย่า Build ทับโฟลเดอร์โปรแกรมที่มีข้อมูลใช้งานจริง
