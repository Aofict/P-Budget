# Frontend modules

โค้ดหน้าหลักที่แยกจาก `app.js` ตามหน้าที่:

| ไฟล์ | หน้าที่ |
| --- | --- |
| `icons.js` | นิยาม SVG ทุกไอคอนผ่าน `PBudgetIcons.render(name)` |
| `finance.js` | ยอดอนุมัติ ยอดเบิกจ่ายสะสม อัตราเบิกจ่าย และส่วนแสดงแหล่งทุนร่วมกัน |
| `navigation.js` | ชื่อหน้า เมนูที่เลือก ไอคอนหัวเว็บ และปุ่มธีม |
| `dashboard.js` | การ์ด Dashboard กราฟรายปี/รายเดือน และช่วงปีปฏิทิน/งบประมาณ |
| `plan-results-table.js` | ตารางเปรียบเทียบ ค้นหา เกณฑ์สถานะ แบ่งหน้า และยอดรวมทุกหน้าตามตัวกรอง |
| `plan-results-table.css` | รูปแบบตารางและตัวควบคุมของหน้าแผนและผล |

## การเชื่อมต่อ

`index.html` โหลดไฟล์ข้างต้นก่อน `app.js` ตามลำดับที่ระบุไว้ โดยใช้ classic scripts เพื่อให้ตัวส่งออก HTML เดิมฝังไฟล์ได้โดยตรง ไม่ต้องเพิ่มขั้นตอน build หรือโหลดไฟล์ผ่านเครือข่ายเมื่อเปิด HTML ที่ส่งออก

`app.js` เป็นจุดประกอบโมดูลและยังรับผิดชอบข้อมูลแอป การเปลี่ยนหน้า ฟอร์ม และการเรียกเซิร์ฟเวอร์ โมดูลใช้ factory ที่รับสิ่งที่ต้องใช้เป็นพารามิเตอร์ ไม่อ่านตัวแปรภายใน `app.js` โดยตรง เช่น Dashboard รับ `getPage()` เพื่ออ่านหน้าปัจจุบัน

Dashboard เรียก `comparisonTable.render({projects, keys, kind})` โดยตารางเก็บสถานะค้นหา/แบ่งหน้าภายในตัวเอง และอ่านโครงการที่เลือกผ่าน callback เพื่อให้การเลือกกราฟยังสัมพันธ์กับตาราง

## ข้อตกลงข้อมูล

- รายการบัญชีรายเดือนมีหน่วยบาท ส่วนผลแสดงใน Dashboard และตารางมีหน่วยล้านบาท
- ข้อมูลที่ขาดเป็น `null` และแสดงขีด ไม่แปลงเป็นศูนย์
- เกณฑ์ผลเทียบแผนอยู่ที่ `resultStatus()` ใน `plan-results-table.js` จุดเดียว
- ยอดรวมตารางรวมทุกโครงการที่ผ่านตัวกรอง รวมทุกหน้าของตาราง

## จุดที่ต้องปรับเมื่อเพิ่มไฟล์

- เพิ่ม script/style ใน `index.html` ตามลำดับ dependency
- เพิ่มชื่อไฟล์ใน allowlist ของ route `/frontend/<name>` ใน `server.py`
- `PBudgetManager.spec` รวมโฟลเดอร์ `frontend` ทั้งหมดไว้ในชุดติดตั้งแล้ว
- CSS ของการ์ดและกราฟยังอยู่ที่ `meeting-app/assets/dashboard-overview.css` ส่วน CSS ของตารางอยู่ในโฟลเดอร์นี้

การเปลี่ยนหน้าและการป้องกันข้อมูลฟอร์มที่ยังไม่บันทึกยังอยู่ใน `app.js` เพราะต้องประสานหลายระบบ ส่วน `navigation.js` จัดการหัวหน้าและสถานะเมนูเท่านั้น
